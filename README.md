Spam Detection Project

Project Overview

This project uses Machine Learning to classify text messages as Spam or Ham (Genuine).

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- TF-IDF
- Multinomial Naive Bayes
- Google Colab

Project Workflow

Message → Text Cleaning → TF-IDF → Naive Bayes → Spam/Ham Prediction

Dataset

The project uses a labelled dataset containing 1400 messages.

Model

A Multinomial Naive Bayes classifier is trained to classify messages into Spam and Ham categories.

Evaluation

The model was evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Classification Report

Project Notebook

The complete implementation is available in "Project_Workshop_Student.ipynb".
